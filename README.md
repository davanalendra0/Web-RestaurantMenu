<h2>🎓 Informasi Proyek:</h2>
<p>Proyek ini adalah representasi digital dari restoran Jepang. Website ini berfungsi sebagai media promosi, menampilkan menu secara visual.</p>
<br>
<h2>🚀 Fitur dan Bagian Utama:</h2>
<ul>
<li>Hero Section: Dilengkapi tagline dan tombol.</li>
<li>Testimoni Pelanggan: Menampilkan ulasan positif dan statistik pelanggan yang puas.</li>
<li>About Us: Menjelaskan misi dan filosofi memasak.</li>
<li>Our Menu: Bagian utama yang menampilkan semua kategori menu.</li>
<li>Terdapat filter untuk mengelompokkan makanan.</li>
<li>Setiap item menu dilengkapi gambar, nama, rating, dan pilihan ukuran/harga.</li>
<li>Newsletter Signup: Formulir untuk pendaftaran email guna mendapatkan penawaran eksklusif.</li>
<li>Footer Lengkap: Menyediakan tautan ke Company, Support, dan informasi hak cipta.</li>
</ul>
<br>
<h2>⚙️ Teknologi yang Digunakan:</h2>
<p>Proyek ini dibangun dengan menggunakan teknologi dasar web:</p>
<ul>
<li>HTML5: Untuk struktur halaman menu, konten, dan formulir.</li>
<li>CSS3: Untuk styling, tata letak fleksibel, dan penerapan desain modern serta responsif.</li>
<li>Deployment: Platform hosting yang digunakan adalah Vercel untuk penerapan cepat dan integrasi Git.</li>
</ul>
